# JobCoach AI - Tailor page (page 2)

Covers user stories #1 Add/Upload Resume, #2 Paste Job Description,
#11 Create Resume from Scratch.

## Run it

1. Install Node.js from https://nodejs.org (LTS version) if you don't have it.
2. Unzip this folder anywhere.
3. Open a terminal in this folder and run:

       npm install
       npm run dev

4. Open the http://localhost:5173/ link it prints.

## Files

- src/pages/TailorPage.tsx - the component. This is the file that goes in the team repo.
- src/App.tsx - temporary shell so the page can be viewed alone. Not needed in the team repo.
- src/styles.css - the shared stylesheet from the HTML prototype.
